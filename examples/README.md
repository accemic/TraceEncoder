# Examples

Reference integrations of C-Trace into SoCs and dev boards.

> **Empty for now.** Examples will land as the core RTL stabilises.
> Planned candidates:
>
> - A minimal testbench-only example that wires the encoder to a
>   stimulus generator and a trace sink.
> - An FPGA-targeted example for a public RISC-V SoC (e.g. one of
>   the cores from [pulp-platform](https://github.com/pulp-platform)
>   or [OpenHW Group](https://github.com/openhwgroup)).
> - A reference design for a Xilinx Kria board (matches Accemic's
>   internal hardware setup).
