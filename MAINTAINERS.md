# Maintainers

This file lists the people who maintain C-Trace. Maintainers have
write access, review and merge PRs, and steer the project's
direction. For machine-readable review routing, see
[`.github/CODEOWNERS`](.github/CODEOWNERS).

## Becoming a maintainer

The maintainer set will grow as the
open-source contributor base does. Sustained, high-quality
contributions (RTL, verification, documentation) and demonstrated good
judgement on reviews are the path in. Reach out to an active
maintainer if you'd like to take on more responsibility.
